# Development priorities

## First public release

Publish the inspectable core, synthetic examples, tests, corrected protocol, and honest limitations. Invite independent reproduction and bug reports. Keep the scope to release of a preliminary report.

## Next evidence milestone

Freeze a preregistered model comparison, run the strong baseline, AGP generator, full AGP, and conventional-plus-verifier ablation under matched conditions, and obtain independent human review. Publish negative findings, uncertainty, costs, and review time alongside improvements. Do not infer hundreds of independent scenarios from repeated runs of 30 cases.

## Next engineering milestone

Add a documented provider adapter and replayable run records. Record the required and achieved checks, verifier identity and scope, source hashes, exact draft hash, policy version, and model configuration. A model may propose findings, but trusted code must enforce release policy.

## Before a real customer pilot

Select one bounded workflow with an accountable owner and establish its baseline error and review cost. Implement permissions, authenticated approvals tied to the exact artifact, source applicability by transaction date, retention, incident handling, rollback, and reviewed source ownership. Validate the policy locally. Make a paid pilot depend on measured usefulness rather than an adoption statistic.

## Business direction

Potential products are implementation assistance, integrations, and maintained workflow policies. Demand, pricing, operating margins, and renewal are untested. Start by asking several workflow owners to identify a recurring error, show the current review process, and agree how improvement would be measured. Interest or GitHub stars alone do not establish willingness to pay.
